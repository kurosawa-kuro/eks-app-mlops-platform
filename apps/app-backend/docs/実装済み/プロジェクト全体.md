# Hono App 実装状況

最終更新: 2025-12-20

## アーキテクチャ概要

```
src/
├── config/          # 設定 (env, logger, ejs)
├── container/       # DI コンテナ (Awilix)
├── domain/types/    # ドメイン型定義
├── adapters/        # 外部システムアダプター
│   ├── cache/       # Rate Limit Store (Memory/Redis)
│   ├── database/    # PostgreSQL アダプター
│   ├── storage/     # S3 アダプター
│   └── token/       # Token Blacklist (Memory/Redis)
├── repositories/    # データアクセス層
│   └── shop/        # EC Shop リポジトリ (Prisma)
├── services/        # ビジネスロジック
│   ├── logs/        # ログサービス (Access/Error)
│   ├── metrics/     # メトリクスサービス
│   └── shop/        # EC Shop サービス
├── middleware/      # ミドルウェア
│   ├── guard/       # 認証・認可・Rate Limit
│   └── observability/ # ロギング・メトリクス
├── routes/          # ルートハンドラ
│   ├── shop/        # Shop (SSR)
│   ├── admin/       # 管理画面
│   └── devtool/     # 開発ツール
├── views/           # テンプレート (EJS)
└── lifecycle/       # シャットダウン処理
```

## 認証・認可

### JWT 認証

- **アクセストークン**: Cookie (`auth_token`) 15分 TTL
- **リフレッシュトークン**: Cookie (`refresh_token`) 7日 TTL
- **トークンブラックリスト**: ログアウト時に無効化

### ミドルウェア

| 関数 | 説明 |
|------|------|
| `authRequired(options?)` | 認証必須 (401 or リダイレクト) |
| `optionalAuth()` | 認証オプショナル |
| `roleRequired(role)` | ロール必須 |
| `permissionRequired(permissions)` | パーミッション必須 |
| `requireRole(role, options?)` | 認証 + ロール |
| `requirePermission(permissions, options?)` | 認証 + パーミッション |

### Rate Limiting

| 関数 | 説明 |
|------|------|
| `rateLimiter(options?)` | カスタムレート制限 |
| `authRateLimiter` | 認証用 (5req/15min) |
| `apiRateLimiter` | 一般API (100req/min) |
